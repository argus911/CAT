# CAT — 行事曆與待辦事項 v3

**Calendar And Todo** — iOS PWA

## 功能
- 年度切換（‹ 年 / 年 ›）+ 點選月份標題快速跳年
- 台灣國定假日匯入（2024–2028）
- 事件與待辦支援**跨多日範圍**，行事曆顯示橫跨色條
- Google Sheets 雲端同步（透過 Apps Script）
- 6 種主題色；PWA 可加入 iPhone 主畫面

## 雲端同步設定
1. Google Sheets > 擴充功能 > Apps Script
2. 貼上 CAT 設定頁面內提供的程式碼
3. 部署為「網頁應用程式」（任何人可存取）
4. 複製 URL 填入 CAT 設定頁面

## 使用
https://argus911.github.io/CAT/
Safari > 分享 > 加入主畫面
